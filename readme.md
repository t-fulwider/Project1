# Welcome to the TFUL Student Database
This is a tree-based student database with more features to be added.

## Background Information
This began as a school project for implementing an AVL tree from scratch. The UI needed for the submission was very minimal and not practical. It was purely for testing the accuracy of the data structure.\ 

Thus, I have implemented a more functional, user-friendly terminal experience. Features included are very basic (searching, adding, removing students). Functions are restricted to whether a user registers as an admin or not. More features can be added in the future.

## How to use
1. Clone the repo
2. Make sure you have g++ installed
3. Open the terminal and switch to this project's directory.
4. Run `g++ -std=c++14 src/*.cpp -o main && ./main`

Data will be written to CSVs created in the "data" folder. You should not need to create these files.
